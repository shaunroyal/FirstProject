# api-service

Use when: the repo is an HTTP or REST API or a backend service, in any language.

| File | Applies to |
| --- | --- |
| `api-design.instructions.md` | API handlers, routes and controllers |
| `api-security.instructions.md` | API handlers, routes, controllers and middleware |
| `api-contracts.instructions.md` | OpenAPI or Swagger specs |
| `api-testing.instructions.md` | API and contract tests |
| `service-operations.instructions.md` | Service config, health checks and containers |
